# [The Garden Beyond](https://nixahsearts.github.io/garden-beyond)

A personal wiki, or "garden", where I share everything
I know about this world in form of an [online
mkdocs book](https://www.mkdocs.org/) hosted on
[GitHub](https://github.com/nixashearts/garden-beyond).

This garden is a fork of Lyz's digital garden, [the Blue
Book](https://lyz-code.github.io/blue-book). If you'd like
to make your own, their guide can also be found here.

**The wiki is meant to be read [in the web
format](https://nixashearts.github.io/garden-beyond).**
